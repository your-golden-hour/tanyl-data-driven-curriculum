# Data-Driven Curriculum

**Команда Tanyl · EdTech Hackathon by Zhambyl Hub · 2026**

**[Открыть MVP](https://your-golden-hour.github.io/tanyl-data-driven-curriculum/)**

Публичная версия выполняет исходное Python-ядро в браузере через Pyodide (WebAssembly).
CSV обрабатываются локально в памяти вкладки и не отправляются на сервер.
При первом запуске требуется интернет для загрузки вычислительных библиотек;
после обновления страницы загруженные пользователем данные сбрасываются.
Четыре вкладки: темы, учебники, часы, данные. Русский и казахский интерфейс.

### Демонстрация за две минуты

1. Дождитесь появления 540 учеников и 12 тем на демо-данных.
2. На вкладке «Темы и сложность» найдите темы с низким освоением.
3. На вкладке «Учебники» сравните средний балл и эффект с поправкой на исходный уровень.
4. В «Рекомендациях по часам» измените чувствительность и проверьте сохранение 81 часа.
5. Экспортируйте Excel либо загрузите CSV на вкладке «Данные».

Демо синтетическое: названия издательств используются для иллюстрации, а результаты
не являются оценкой их реальных учебников. Сравнения наблюдательные, без причинных выводов.
Часть пояснений и названия тем пока остаются на русском при казахском интерфейсе.

### Статическая сборка

```bash
python scripts/build_static.py
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

GitHub Actions проверяет тесты и публикует `dist` в GitHub Pages.
Эту же папку можно разместить в Cloudflare Pages. Сервер Flask ниже предназначен
для локального использования: его состояние общее в пределах процесса, поэтому
не публикуйте Flask без добавления изоляции пользовательских сессий.

Интеллектуальная система оценки эффективности учебников и учебных программ.
EdTech-платформа для методистов: по результатам тестирования школьников помогает
принимать решения об учебниках и учебных часах на основе **измеримых результатов**,
а не субъективных оценок.

> Интерфейс двуязычный: русский / қазақша (переключатель в шапке).

## Что умеет платформа

| Требование кейса | Как реализовано |
|---|---|
| Анализ результатов по темам | Средний балл, медиана, доля освоивших (порог 60 %), 95 % доверительный интервал |
| Выявление сложных разделов | Индекс сложности `0.6·(100 − ср.балл) + 0.4·(100 − доля освоивших)`; уровни *критическая / повышенная / норма* по z-оценке относительно всех тем и абсолютному порогу освоения |
| Сравнение учебников | Рейтинг **с поправкой на исходный уровень учеников** (OLS-регрессия по `prior_score`), ANOVA между учебниками, по каждой теме — t-тест Уэлча и d Коэна |
| Рекомендации по часам | Перераспределение при **неизменной общей нагрузке**: больше часов сложным темам, меньше лёгким; ограничение ±35 % на тему (строго, с целочисленными границами), минимум 2 ч, округление методом наибольшего остатка; для каждой темы — текст-обоснование и оценка надёжности по размеру выборки |

Дополнительно: загрузка собственных CSV, экспорт отчёта в Excel, REST API, ползунки настройки рекомендаций.

## Формат данных

**Результаты тестов** (`results.csv`), одна строка = результат ученика по теме:

| Колонка | Обязательно | Описание |
|---|---|---|
| `student_id` | да | идентификатор ученика |
| `textbook` | да | учебник, по которому учится ученик |
| `topic` | да | тема |
| `score` | да | набранный балл |
| `max_score` | нет | максимум (по умолчанию 100) |
| `section` | нет | раздел программы |
| `prior_score` | нет, **но рекомендуется** | исходный уровень ученика (напр. прошлогодняя оценка, входной тест) — включает поправку при сравнении учебников |
| `school`, `class_id` | нет | сохраняются, пока в расчётах не используются |

**Учебный план** (`curriculum.csv`, необязательно): `topic`, `hours`, `section`.
Шаблоны скачиваются на вкладке «Данные». Кодировки: UTF-8 и Windows-1251, разделитель определяется автоматически.

## REST API

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/report?max_change=0.35&sensitivity=1&min_hours=2` | полный отчёт (JSON) |
| POST | `/api/upload` | поля `results` (CSV), `curriculum` (CSV, необязательно) |
| POST | `/api/demo` | вернуть демо-данные |
| GET | `/api/export.xlsx` | отчёт в Excel |
| GET | `/api/template/{results,curriculum}.csv` | шаблоны |
| GET | `/api/health` | проверка работоспособности |

## Методологические оговорки

- Учебник закреплён за школой, поэтому различия могут отражать и школу, а не только учебник. Для надёжных выводов нужны данные нескольких школ на каждый учебник и поле `prior_score`.
- Рекомендации по часам — **поддержка решения**, а не автоматическое решение: итог за методистом.
- Демо-данные синтетические; выводы на них иллюстративны.
- Локальный Flask хранит данные в памяти процесса; публичная версия — в памяти вкладки браузера. Для постоянного хранения нужны отдельные БД и авторизация.
